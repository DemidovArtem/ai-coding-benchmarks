# Scikit-learn configuration pilot — frozen execution protocol

Frozen 8 November 2026, before measured inference. This is a separate cohort from ripgrep. The authorized matrix is baseline, Caveman, Ponytail and Serena, six successive SWE-Milestone changes, two independent repetitions: eight trajectories and 48 dependent step observations. Task order is M06, M11, M12.1, M12.2, M01, M03, the pinned dataset's Strong-dependency-closed prefix. Run every method on a step before advancing; finish repetition one before starting repetition two cold. No plan variants or extra tasks are included.

## Fixed inputs and continuity

The source dataset remains commit `3500478e740d42583277c2658aa7729eb36e10f4`; repository metadata, CSV, SRS, classification and repository/quarantine configuration hashes are pinned in `scikit_experiment.json`. All methods use the same immutable scikit runtime, Codex CLI 0.163.0, `gpt-6.1-sol`, high reasoning and ChatGPT OAuth. No paid API or custom endpoint fallback is allowed. Runtime identity and offline Python MCP evidence are recorded separately from measured task tool use. Retained Ponytail 5.3.2/full and Caveman v4.0.1 assets remain unchanged. Their historical Node file has moved in the global app cache, so the new installer verifies the identical baked Node bytes rather than modifying historical manifests.

The common source is prepared through the pinned harness's normal history truncation, masking, comment cleanup, squashing and protected quarantine. A host-created preflight submission tag captures unchanged source for infrastructure evaluation; it is removed before every cold measured run. No preflight host tag counts as an agent submission. All methods start from the identical prepared source tree.

Every step gets a fresh disposable container. Its original image Git history is removed and replaced by the verified common source bundle plus only its own parent trajectory's incremental bundle. Native session history and closed SQLite backups are restored for continuations and checked by the existing local history reader. The model receives exactly one current task through a verified first shell read. Prior submission tags must remain unchanged, and new source must descend from the exact parent. No grader or Sonar feedback reaches the model. There are no automatic model retries or silent context amendments.

Serena performs required cold onboarding on each independent repetition. Between tasks it receives only its own exact previous memories and native session; retained-memory reads, semantic calls and memory writes are audited. Cython contributes to physical footprint but is outside Python semantic/Sonar coverage. Native skill startup hooks run on each cold/resume invocation; only model-turn audit evidence establishes actual native activation.

## Measurements and interpretation

Primary correctness evidence is the original grader's raw resolution and regression counts, per task and per trajectory. Valid unresolved results remain unresolved; infrastructure failures become missing correctness scores. The unchanged M06 base preflight runs 36,921 tests and has **78 missing P2P tests** before any model changes, with no P2P failures and 0/5 F2P fixes. This existing test-discovery/compatibility limitation must accompany comparisons; future unresolved outcomes cannot be attributed entirely to model edits. Original tests, grader and quarantine are not relaxed to improve scores.

Python/Cython footprint counts physical lines, including comments and blanks, in `.py`, `.pyx`, `.pxd` and `.pxi` files under metadata source roots. Metadata tests/exclusions/generated paths and vendor/generated/cache directories are excluded. Binary files are reported separately. Both cumulative changes from the common base and incremental changes from the previous submission are retained. Cross-boundary renames count the full source entering/leaving production scope. This differs from the historical Rust AST filter and is never pooled with it.

Sonar uses the pinned local server and a separate frozen Python Sonar way profile/rule hash, covering exactly captured production `.py` bytes. The first common-base scan verifies all 264 selected Python files. Cython is explicitly excluded from Sonar; no Clippy applies. Changes are deltas from this repository's identical common base, not absolute cross-language comparisons. Static complexity and remediation estimates do not establish architecture quality or human review effort. Token counters are cumulative native counters with per-step differences; OAuth token use is not API billing.

## Storage and stop conditions

Keep only one active agent container, the shared runtime and the active task grader. Save each completed step before removing its container. Each source bundle contains new trajectory commits relative to the shared immutable base bundle, which must remain available. Save exact snapshots, closed native databases, native rollouts and Serena memories. Grader evidence may be compressed only after every archived file hash is verified. Temporary host metric repositories and scanner staging are reconstructible and removed after collection. Private authenticated state is ignored, not published.

Require at least 1 GB free on the workspace and 12 GB on the Docker filesystem before a model invocation. The workspace reserve is an explicit new-cohort setting; historical reserves are unchanged. Check the current-task grader digest before inference. The complete image set is not acquired at once. Stop on quota pressure (85%), model refusal, missing image, low disk, broken quarantine, missing source/session/memory evidence, or invalid grader/Sonar collection. Failed attempts and their containers remain available for explicit recovery; do not replay a completed prefix. A future task's image acquisition and expanded peak must pass the same storage check before that task starts.

## Current evidence boundary

Public release reproduction checks previously covered analysis rendering and harness logic. The new preflight additionally covers a real unchanged-source grader run, a real offline Python MCP call and a real common-base Python Sonar scan. It does not prove fresh-machine portability, measured method effectiveness, or native continuation on scikit-learn before those turns actually run. With only two independent trajectories per method, this remains exploratory and does not establish statistical superiority.
