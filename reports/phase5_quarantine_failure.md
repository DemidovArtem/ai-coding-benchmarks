# Phase 5: остановка quarantine preflight

21 октября 2026 года, около 16:40 Europe/Zurich, первый шаг `phase5_ponytail_r02_s01` остановлен до активации профиля, выдачи задания и вызова модели. Сессия executor не создана; grader, production LOC и token metrics отсутствуют. Попытка сохранена в общем JSONL и отдельном report. Это infrastructure failure, а не результат качества Ponytail.

Frozen upstream сообщил: `Quarantine verification failed: denied host 'static.crates.io' is still reachable`. Повторный TCP-only probe из того же контейнера воспроизвёл соединение к `199.232.142.137:443`. Firewall имеет OUTPUT policy DROP, но содержит явное правило ACCEPT для `199.232.142.137/32`. Этот адрес не входит в объявленные deny ranges `151.101.0.0/16` и `146.75.0.0/16`. Ответ registry по HTTP или содержимое crate для диагностики не требуются и не загружались. [Машинные доказательства](phase5_quarantine_failure.json).

Механизм: allowlist допускает IP, который DNS запрещённого registry теперь также возвращает; frozen CIDR exclusions этот IP не покрывают. Это подтверждённая недостаточность текущей сетевой политики. Конкретный allowlisted hostname, который первоначально добавил IP, не установлен; для объяснения наблюдаемой доступности он не требуется. Защита сработала на preflight и остановила запуск.

К этому моменту завершены 6/8 траекторий и 12/16 правок. Все 12 приняты grader, собраны без collection errors и проверены Sonar. Baseline и Caveman имеют по два полных повтора; Ponytail и plan — по одному. Их прежние preflight проверки прошли, но это не доказывает неизменную недоступность registry на всём протяжении модельных запусков. Новая диагностика не доказывает использование этого канала предыдущими моделями; результаты и это ограничение сохраняются совместно.

Очередь остановлена. Вторые повторы Ponytail и plan остаются 0/2. Ошибка preflight сохранена; повтор под прежним ID запрещён. Не выполнялись изменения evaluator, scoring, benchmark quarantine или host firewall. Не запускались дополнительные модели, загрузки образов и новый cohort. Неуспешный контейнер остановлен, его исходники и диагностические артефакты сохранены.

Перед следующими model trials требуется исправить registry isolation и проверить его без модели. Изменение сетевой политики требует нового pinned cohort и соответствующей baseline; результаты разных условий нельзя выдавать за завершение прежнего парного сравнения. Полная исходная матрица остаётся незавершённой.
